# 变量控制排演板

供参加科学探究活动的少年在**动手前**理清实验条件、**动手时**记录数据、
**分析时**看见问题的一块「排演板」。

- **后端**：Python + Flask，SQLite 持久化（`inquiry.db`），负责平衡随机排演、
  四类检查、统计、冻结快照与随机依据回放。
- **前端**：原生 HTML / CSS / JavaScript，无构建步骤、无第三方库；
  可拖拽因素卡片、横向时间轴、Canvas 结果图、打印实验单。

## 运行

```bash
pip install -r requirements.txt
python app.py                 # 自动建库并启动，默认 http://127.0.0.1:5000
python seed_demo.py           # 可选：灌入「光照 × 绿豆发芽」演示探究
```

测试：

```bash
python -m pytest tests/ -q
```

## 使用流程（对应页面 ①～⑧）

1. **写假设**：探究名称、「如果……那么……因为……」假设、重复次数、随机种子。
2. **拖卡片归类**：把因素拖进「自变量 / 因变量 / 控制变量」三个篮子，
   自变量填水平、因变量填单位、控制变量填固定值。
3. **资源**：每种材料的每轮份数与库存、每个可用时段能同时容纳的轮数。
4. **检查 → 排演**：系统先报问题，再用**固定种子**做区组平衡随机
   （每个水平组合次数相等、每区组含全部组合各一次，区组内 Fisher–Yates 洗牌）。
5. **执行**：在时间轴上打开轮次，录入带单位的测量值、异常原因；
   可勾选「本轮已完成并锁定」。
6. **条件变化**：直接再点「排出实验次序」——已锁定轮次保留原位、测量随轮次迁移，
   只对未完成部分续排；「全部重排」会忽略锁定。
7. **看结果**：各水平并排显示原始数据、均值、极差，柱图上叠加极差线与原始点；
   单位混用、缺测、直接剔除异常值会逐条提示并可点击定位到轮次。
8. **冻结 / 回放 / 打印**：冻结后版本只读并存快照；
   回放用同一种子重放每次洗牌并核对；打印输出含材料、步骤、空白记录格的实验单。

## 检查项（`checks.py`）

| 代码 | 时机 | 含义 |
|---|---|---|
| `W_UNCLASSIFIED` | 设计 | 还有因素没归类（可点击定位卡片） |
| `W_NO_IV` / `W_NO_DV` | 设计 | 缺自变量 / 因变量 |
| `W_IV_LEVELS` | 设计 | 自变量不足 2 个水平 |
| `W_NO_CONTROL` / `W_CONTROL_VALUE` | 设计 | 控制变量遗漏或没填固定值 |
| `W_UNEVEN_REPEATS` | 设计 | 各水平组合重复次数不均（含锁定后续排导致的失衡） |
| `W_MULTI_IV` | 设计 | 相邻两轮同时改动多个自变量，定位到轮次 |
| `W_SLOT_OVER` / `W_SLOT_SHORT` | 设计 | 时段超容量 / 有轮次排不进时段 |
| `W_MATERIAL` | 设计 | 材料总需求（每轮份数×轮数）超过库存 |
| `W_MISSING` | 执行 | 已锁定轮次缺测（未完成的轮不催促） |
| `W_UNIT_MIX` | 分析 | 录入单位与因变量设定单位不一致，定位轮次 |
| `W_EXCLUDED` | 分析 | 异常值被直接剔除，不进入均值/极差，提醒在报告中说明 |

## 文件说明

```

app.py            Flask 路由、序列化、统计、冻结快照

static/style.css  样式（含打印实验单的 @media print）

tests/test_app.py 端到端测试（Flask 测试客户端）
seed_demo.py      演示数据
```

## 随机依据（可回放）

每次排演把种子（基础种子 + 版次）、输入参数（组合、重复数、锁定位置）
和每次 Fisher–Yates 洗牌的**全部随机选中位置**写入 `rng_log` 表。
回放时用同一种子重新生成随机数序列逐条核对，全部吻合即显示「✓ 一致」，
适合课堂上回答：「这个次序是怎么排出来的？换个人还一样吗？」
